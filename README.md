# Azan Watch v2.0 — اذان واچ

## نئی خصوصیات / تبدیلیاں
- **مکمل آف لائن**: `adhan` لائبریری اب مقامی (`adhan.js`) ہے، CDN پر انحصار ختم؛ service worker اب واقعی cache کرتا ہے۔
- **اذان صرف ایک بار**: پہلے ہر 15 سیکنڈ پر بار بار بجتی تھی اور طلوعِ آفتاب پر بھی؛ اب صرف پانچ نمازوں پر، ایک بار۔
- **عصر کا مذہب**: ڈیفالٹ حنفی (پہلے شافعی تھا)، ترتیبات میں تبدیل ہو سکتا ہے۔
- **اگلی نماز + کاؤنٹ ڈاؤن**، موجودہ نماز نمایاں، **اقامت کاؤنٹ ڈاؤن** (منٹ ترتیبات میں)۔
- ہر نماز کے لیے **منٹ ایڈجسٹمنٹ**، 12/24 گھنٹے، جمعہ کا لیبل۔
- **ہجری تاریخ** (مغرب سے بدلتی ہے، ± دن ایڈجسٹمنٹ) اور **شمسی تاریخ** مہینوں کے اردو ناموں کے ساتھ۔
- شہروں کی فہرست (بٹگرام سمیت) + GPS؛ تمام ترتیبات `localStorage` میں محفوظ۔
- اپنی **اذان کی آواز** اپ لوڈ کریں (IndexedDB میں محفوظ رہتی ہے)، والیوم، ٹیسٹ/بند بٹن، براؤزر نوٹیفکیشن۔
- **مسجد ڈسپلے موڈ** (فل اسکرین + اسکرین آن رکھنا؛ ڈبل کلک سے واپسی)۔
- manifest درست (`start_url`, `scope`, `id`, اردو/RTL) اور HTML میں link/registration شامل۔
- Electron: اذان بغیر کلک کے بجتی ہے، single-instance، F11 فل اسکرین، پس منظر میں بھی وقت پر؛ Windows EXE/Installer اور Linux AppImage بنانے کا `electron-builder` سیٹ اپ۔
- GitHub Actions: `build-desktop.yml` (EXE/AppImage) اور درست شدہ `build-twa.yml` (APK، Java 17)۔

## استعمال
**براؤزر/PWA**: تمام فائلیں HTTPS سرور (یا `npx serve .`) پر رکھیں اور `azan-watch.html` کھولیں۔ سیدھی فائل کھولنے پر بھی چلتا ہے مگر service worker/انسٹال کے لیے http(s) ضروری ہے۔

**ڈیسک ٹاپ**:
```
npm install
npm start            # چلانے کے لیے
npm run dist:win     # Windows installer + portable EXE (Windows پر)
npm run dist:linux   # AppImage + deb (Linux پر)
```
GitHub پر push کر کے Actions → *Build Desktop* سے بھی بن جاتا ہے۔

**اینڈرائیڈ**: سائٹ HTTPS پر ہوسٹ کریں، پھر Actions → *Build Android TWA* میں `site_url` دیں۔ (اپنا package id `com.example.azanwatch` بدلنا چاہیں تو bubblewrap کے سوالات میں دیں۔)

## نوٹ
- اوقات فلکیاتی حساب (adhan) سے ہیں؛ مقامی جنتری سے تصدیق اور ضرورت ہو تو منٹ ایڈجسٹ کریں۔
- ہجری تاریخ ام القریٰ کیلنڈر پر مبنی ہے؛ پاکستان میں رویتِ ہلال کے مطابق ± دن سے درست کریں۔
